# Copy that fits the offer

Use plain, specific language that still makes technical sense. Start with the result or a recognisable frustration. The rehook is the short line directly under the hook; it can be as short as the hook. Preserve approved openings while changing the body.

When the user gives an idea or scenario, develop it rather than transcribing it literally. When they select exact wording, keep it. Deliver one complete draft per requested post unless alternatives are requested.

For a lead magnet, useful ingredients are:
- A desirable outcome and a concrete problem the reader recognises.
- Relevant, verified evidence or authority.
- What the resource helps the reader do.
- What they receive and how they can start using it.
- What becomes easier, clearer or possible afterwards.
- One clear CTA matching the actual delivery method.

Use only the parts that help. Do not mechanically repeat the same sections in every post. Explaining both a capability and its practical payoff can amplify value; repeating the same claim twice does not.

Keep the exact installation, prompts, setup and worked examples in the download. Give enough information for an informed request: resource format, useful contents, audience and outcome. Do not make an opt-in so mysterious that readers cannot understand what they are requesting.

Use real contents and examples. Do not invent bonuses, savings, speed claims, results, scarcity or guarantees. Do not present a curated third-party skill as the user's creation: link its original creator and preserve attribution. A resource not yet created is not a published gift.

Vary the evidence across a batch without inventing new numbers. Preserve the user's chosen phrasing when accurate. Recheck time-bound claims before reusing them later. A usage metric does not prove one new resource caused all of that usage or delivered an unmeasured result.

Match the CTA to the actual gift and channel. Include connection/eligibility requirements when needed; do not invent repost incentives. Drafting the copy does not authorize posting it or messaging people.

Before delivery, compare the caption with the matching visual and resource. Check hook/rehook, numbers, product names, keyword, ownership, compatibility and what is actually included. When asked for all posts, show every complete copy, not only the changed sentences.
